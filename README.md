# 🌱 Instituto Kaleo

Projeto desenvolvido como parte da disciplina **Experiências Práticas – Construindo Interfaces Web Modernas**.

## 🧭 Descrição
Plataforma institucional para o Instituto Kaleo, com informações sobre projetos sociais, cadastro de voluntários e interface responsiva.

## 🚀 Tecnologias Utilizadas
- HTML5 semântico
- CSS3 com Design System e Grid
- JavaScript modular (SPA + LocalStorage)
- Git/GitHub + GitFlow
- Acessibilidade (WCAG 2.1 AA)
- 🌙 Modo Escuro persistente via LocalStorage

## ♿ Acessibilidade
- Navegação por teclado
- Contraste 4.5:1
- Modo alto contraste e modo escuro
- Textos alternativos em imagens
- Estrutura semântica
